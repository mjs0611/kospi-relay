## 검증

기존 가상환경에서 `test_missing_prices.py`, `test_headline.py`, `test_signal_evaluation.py`, `test_web.py`를 각각 실행해 통과했습니다. 웹 21개 테스트와 가격 누락·자료 복원·헤드라인·시그널 검산을 포함합니다. 여섯 열과 원본 날짜 링크 보존, 키보드 스크롤 영역, 회사 복귀·본문 이동 계약을 추가로 확인합니다.

운영 가격을 새로 조회하지 않았습니다. 기존 `origin/gh-pages` 스냅샷의 가격·문구를 보존한 채 새 셸·CSS·표 래퍼를 적용해 픽셀을 검토했습니다. 실제 생성기는 별도의 오프라인 fixture 테스트로 검증합니다. 이 미리보기는 게시용 빌드가 아닙니다. 56개 기존 페이지의 내부 참조 886개에 파일·앵커 누락이 없었습니다.

Chrome/WebKit 320·390·1440px, 글자 200%, 감소된 모션, 방향키 표 스크롤, 날짜 이동·뒤로가기, 공유·클립보드 실패 시 기록 페이지 복귀, JavaScript 없는 화면과 axe 결과는 작업공간 `evidence/web-services/verification.json`에 보존합니다. 전후 픽셀은 `before/`, `after/`에 있습니다. 외부 광고·글꼴 요청은 차단해 글꼴 실패 시 화면도 확인합니다.

두 서비스 합산 46개 브라우저 흐름과 axe 12회 검사를 통과했으며 위반·페이지 실행 오류는 0개입니다. 별도 주요 12페이지 콘솔 검사에서도 애플리케이션 콘솔 오류·로컬 HTTP 오류는 0개입니다. 의도적으로 차단한 외부 요청은 `console.json`에서 따로 확인할 수 있습니다.

Mac 기본 WebKit 러너는 Tab 순서에서 링크를 생략합니다. Chrome에서는 첫 Tab을, WebKit에서는 링크 초점 후 Enter를 검사합니다. 초점을 둔 표의 기본 방향키 스크롤도 WebKit에서 작동하지 않아 방향키·Home·End를 직접 처리합니다. 링크에 초점이 있거나 조합키를 누르면 기존 키 동작을 그대로 사용하며, 키보드 이동에 애니메이션은 없습니다. 운영 배포·원격 push·DNS·운영 데이터 쓰기는 하지 않았습니다.
